# Algorithmic Trading

[![License: CC BY 4.0](https://img.shields.io/badge/License-CC%20BY%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/)

A collection of Python notebooks exploring quantitative finance, algorithmic trading, financial NLP, and market modelling.

## Contents

- **Technical indicators** — live stock-market analysis using technical trading indicators and Yahoo Finance data.
- **S&P 500 Tracker** — market tracking and exploratory analysis of S&P 500 securities.
- **FinBERT sentiment strategy** — financial sentiment analysis and sentiment-informed trading using FinBERT.
- **LSTM forecasting** — time-series stock-price prediction and risk analysis using recurrent neural networks.
- **German Lobby Register** — exploratory analysis of German lobbying data.
